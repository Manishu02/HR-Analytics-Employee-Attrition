📊 HR Analytics Project – Employee Attrition Analysis

📌 Project Overview

This project analyzes employee attrition patterns using HR data. The goal is to identify key factors influencing employee turnover and provide insights for better decision-making.

📊 Dashboard

🔍 Key Insights
High attrition observed in Sales department
Low income group shows higher employee exits
OverTime significantly impacts attrition
Employees aged 26–35 are most affected
Junior roles have higher turnover
