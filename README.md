# 📊 HR Analytics Project – Employee Attrition Analysis

This project analyzes HR data to understand employee attrition patterns and identify key factors influencing employee turnover.

---

## 📌 Project Overview

- Analyze employee attrition trends  
- Identify key drivers of employee turnover  
- Support HR decision-making  

---

## 🧹 Data Cleaning

- Handled missing values  
- Removed duplicate records  
- Checked dataset structure  
- Prepared data for analysis  

---

## 📊 Exploratory Data Analysis

- Attrition by Department  
- Attrition by Job Role  
- Attrition by Age Group  
- Attrition by Income Level  
- Attrition by OverTime  

---

## 🔧 Feature Engineering

- Created `Attrition_Flag` (Yes → 1, No → 0)  
- Created `Income_Level` (Low, Medium, High)  

---

## 📊 Dashboard

Power BI dashboard created to visualize employee attrition insights.

---

## 🔍 Key Insights

- Sales department has highest attrition  
- Low income employees leave more  
- OverTime increases attrition  
- Age group 26–35 most affected  
- Entry-level roles show higher attrition  

---

- Python (Pandas)  
- Power BI
